# 音栈 v1.3.0（94）· 发现页去广告 + 收缩态命中修复 + 弹簧丝滑底栏

本目录是「音栈 v1.3.0」（`94 / 1.3.0`）的交付快照。在三件事（底栏伸缩换成渲染线程弹簧、毛玻璃与流光整体移除、全项目字号归进阶）之上，本版再修两处：

- **发现页去广告**：直连各平台官方 banner 接口拉到的投放条目（网易云 `typeTitle='广告'` / `targetType=3000` / `adid` 非空，酷狗 `type===3` 或标题含「广告」）在解析层直接丢弃，首页 banner 与「推荐 ›」全量页共用过滤，只呈现能落到 App 内详情页的内容。
- **收缩态命中修复**：底栏收缩时三枚「底栏按钮」的命中层改为条件挂载（仅 `t() < 0.42` 展开过程中存在），彻底消除「底栏已收起、点播放栏原位置却跳到发现/设置」的穿透误触。

## 一、发现页：只呈现能落地的条目

banner 接口本身就是各平台卖广告的地方，正版内容与投放混在同一个数组里返回。`isAdBanner()` 任一命中即丢弃：

| 判据 | 说明 |
| --- | --- |
| `typeTitle` 含「广告」 | 网易云会直接标出来 |
| `targetType === 3000` | 站外活动页，App 内没有容器 |
| `adid` / `adSource` 非空 | 投放系统编号，广告位专属 |

酷狗侧另加 `type === 3` 或标题含「广告」丢弃。真实返回体验证：6 条 → 保留 5 条、精确丢弃王老吉那条 `('广告', 3000, http://wlj2015.qq.com/)`。静止自检 BM 组新增护栏：`DiscoverFeed` 里必须有 `isAdBanner(` 且含「广告」判据，否则 FAIL。

## 二、底栏伸缩：从「四层平滑」到一根弹簧

旧的吸附是 JS 16ms 定时器手搓缓动 → 1/40 分段广播 → 24ms 节流 → 渲染端 45ms 线性补间，四层平滑叠出「阶梯滑入」。现在：

| 环节 | 旧 | 新 |
| --- | --- | --- |
| 松手吸附 | JS 定时器缓动，60Hz 采样 | 只决策终点（保留甩动方向判定），一次性下发 |
| 渲染平滑 | 45ms 线性补间 | `springMotion(0.24, 0.86)` 可中断弹簧 |
| 插值帧率 | ~40Hz 阶梯 | 渲染线程原生帧率（120Hz 屏 120 帧过渡） |

弹簧每次从「当前值 + 当前速度」重定目标，段间速度连续；JS 侧同时省掉每秒几十次定时器与广播。切页 / 进出二级页这类要干脆的复位仍直接到位。

## 三、毛玻璃与流光整体移除

| 删除项 | 原因 |
| --- | --- |
| 底栏 `backgroundEffect` 实时模糊 | 背后是滚动列表，每帧重算，最大掉帧源 |
| 跟手流光 + 按压充能 | 逐帧渐变重绘 + 16ms 定时器，纯装饰 |
| 整屏触摸旁路监听 | 每指每帧进 JS，只为给流光广播坐标 |
| `ui/Shell.ets` 整文件 | 零引用死代码（HdsGlass / HdsFlowLight 等） |
| 「流畅优先」开关整链 | 毛玻璃没了，开关失去意义 |
| `UIMaterial.state` 元数据 | 唯一消费方已删 |

底栏表面定版为三层纯静态绘制：实色底（深 `#C71A1D24` / 浅 `#E6F6F4EE`）+ 固定 150° 受光渐变 + 0.5vp 发丝边，滚动期间零重算。静态自检的材质断言同步反转为「出现 `backgroundEffect` / `backgroundBlurStyle` / `uiMaterial` 即 FAIL」。

## 四、排版细节

- 全项目 30 处裸字号归档进 `FONT` 阶：`9→micro(10)`（可读性地板）、`13→callout(14)`、`15→body(16)`、播放页标题 `23→title(26)`；
- 迷你条收起态：歌手行隐藏、歌名放开两行居中（纯属性切换，不增删节点）；
- 动效选型规矩：跟手用 `springMotion`，一次性转场用 `duration + 曲线`。
