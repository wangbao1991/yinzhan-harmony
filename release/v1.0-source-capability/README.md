## 本轮改动

按「软件能支持更多的音源，也能把音源要求的东西给它适配，但不要跟现有工程冲突，本质还是听歌、下载」的口径，
**只补音源运行时能力与音源脚本要求的配置**：

- 运行时新增 8 类高频能力分派（导入歌单 / 专辑 / 榜单 / 推荐 / 单曲信息 / 搜专辑），
  按插件**实际导出**声明能力，不伪造；`actions` 协议三值 `musicUrl / lyric / musicSearch` 不变，不污染取链取词。
- `env.getUserVariables()` 从写死 `{}` 改为真实 getter，保存配置后即时生效；
  用户变量按音源实例隔离，**只存本机、不进备份**（避免凭证外泄 / 串号）。
- 落点**只在音源管理页既有菜单「配置与能力」**，试跑结果只进播放 / 下载出口；
  **零新增路由、内容页零改动**。
- `webdav` / `pako` 继续如实标注不支持。
