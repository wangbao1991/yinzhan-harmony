# 音栈 · 音源订阅清单（能力扩展版附带交付物）

> 本清单是**附带交付物，不写进工程代码**。数据来源：本轮在 GitHub 仓库/网页检索到的 243 份真实音源样本，逐份用工程里的 `MFRuntime.load()` 真实装载后读出的「实际导出能力」与「用户变量声明」，未装载成功的如实标注。

> 用法：音源管理 → 右上「+」→「从网络导入」，粘贴下面的直链（国内网络可用 proxy 形式）。导入后按音源卡片菜单的「配置与能力」查看它真正支持什么、填写它要求的变量。
