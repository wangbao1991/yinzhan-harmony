## 二、`selfcheck.py` 断言成对改写（关键）

运行时零引用 ≠ 可删。这 4 项里有 3 项被断言锁死，若只删源码会让自检全红。本轮逐组处理：

| 断言组 | 处理 |
|---|---|
| **AT**（真实收听统计层） | 整组退役（删 50 行）：原要求 `PlayStats.ets` 存在、`Player` 三处埋点、`PLAY_STATS` 键、init 顺序 Store→Library→PlayStats→Player |
| **AU**（月·回响数据地基） | 整组退役（删 35 行）：原逐一点名 `hourBuckets` / `trendPoints` / `topArtist` / `newSongsInRange` / `reportOf` / `MonthReport` 等必须存在 |
| **AC** 4 处 | ① 删 `stats` 变量定义（原读 `PlayStats.ets`）；② reload 断言由「Library / PlayStats 双条件」改为「Library 单条件」，文案同步改；③ 删 v2.29 残留反向断言里的 `PlayStats` 项；④ 光感提示 6 条存在性断言整段删除（27 行），保留后续 ⑤⑥⑦ 依赖的 `art_page` / `ab_src` 变量定义 |
| **AS** | 注释与 PASS 文案由「统计底层保留但不再参与界面」改为「已整体清除」；AS 其余（看板/报告卡已下线）不动 |
| **AV / AW** | 保持原样。这两组是**禁止性**断言（要求报告页/路由/首页报告卡不存在），与底层统计层无关，不受影响 |
| **BD** | 外观页必备选项去掉 `'光感四档已取消'`、`'知道了'` 两项（提示条已删，留着会误报 FAIL） |
| **CA** | ④ 由「提示条必须存在」翻转为「提示条不得回潮」；docstring 与 PASS 文案同步改为「已删除」；CA ③ 的 `'光感选项已移除'` 是青绿主题旧说明的禁止性断言，与本项无关，保留 |
| **BP / BQ / CD** | 保持原样。B6 删的是 `status()` 内部早退分支，签名与文案链路未动，这几组检查的是签名、clean 判定、平台中性文案与心跳，均仍然成立 |
| **CY**（新增） | 新增守护组并注册到 `main()`：用 `load_raw()` 读磁盘原文，锁死 ① B1/B2 统计层 8 类符号全清零且 `PlayStats.ets` 不存在；② B5 提示链 7 类符号（含中文文案与 `Text('知道了')`）全清零；③ B6 早退分支 / 空态构造 / 注释全清零，同时 `status` / `label` / `toastText` / 心跳 / 对账仍在；④ B11 保留项与玻璃四件套订阅完好。既防「没删干净」，也防「误删保留项」 |

> 断言总数从 78 项变为 77 项：AT、AU 两组 PASS 退役（-2），CY 组新增 1 条 PASS（+1），净 -1，符合预期。
