真机上为什么是白板：玻璃叠在了白底上

截图里那块面板几乎是纯白，看不出磨砂、高光和阴影——不是参数没调好，是它背后根本没有东西可透。这一版把面板从 bindSheet 里搬出来自己画。

根因：bindSheet 的容器自带一层不透明白底，backgroundColor: '#00000000' 在这版 SDK 上不生效。 62%~72% 的白玻璃叠在白底上，结果就是 100% 白；backdropBlur 模糊的是一张白纸；投影也落在白底上，看不出层次。四层结构全都白做。

右边能看到封面从玻璃里透出来的暖色和冷色、顶部一条亮带、边缘一圈细白线，以及落在封面上的深投影。左边四条边是干净的白，没有一处透光——这就是「背后是白纸」的样子。

三个诊断

① 容器白底

sheet 的背景设全透明无效，面板实际叠在系统白底上，62% 白 → 纯白。

② 模糊没有对象

backdropBlur 模糊的是 sheet 自己的白底，等于没做磨砂。

③ 阴影被吃掉

投影画在白底上，与白卡同色系，几乎不可见，卡片就「贴」在屏幕上。

改法：把它从 sheet 里搬出来

播放页根节点本来就是 Stack，直接在它最上层加一个自绘浮层：压暗遮罩 + 玻璃卡片。这样卡片背后就是真实的封面，四层结构才成立。

// PlayerPage 根 Stack 末尾 if (this.panel === 4) { this.queueOverlay() } // 浮层：遮罩 + 卡片，只有两层 Stack({ alignContent: Alignment.Bottom }) { Column() .backgroundColor(withAlpha('#000000', 0.22)) // 压暗，点一下收 .onClick(() => this.closeQueue()) QueueSheet({ onClose: () => this.closeQueue() }) .width('100%') .height('86%') // 顶部露出封面 .padding({ bottom: this.bottomSafe }) .transition(TransitionEffect.OPACITY .combine(TransitionEffect.translate({ y: 90 })) .combine(TransitionEffect.scale({ x: 0.97, y: 0.97 }))) } // bindSheet 从此只管音质 / 更多 / 歌词搜索 / 失败面板 .bindSheet(this.panel > 0 && this.panel !== 4, this.panelContent(), { ... })

顺带调的两个数

项改前改后为什么
玻璃填充白 72%白 62%72% 叠深色封面已接近不透明；降到 62% 后封面明暗能透出来，高光那圈白才有对比
顶部高光白 58%白 78%填充变淡后，高光需要更亮才「打」得出来；顶部叠出来约 92% 白，形成一条亮带
底部回光白 14%白 20%下沿有反光，玻璃才有厚度，不是一张纸

填充值不能一直往下压：62% 白配 #16181D 正文约 6.5:1，再淡就掉到 4.5:1 以下。自检里把区间锁在 55%~75%，越界直接 FAIL。

入场动画

原来 sheet 自带升起动画，自绘要自己给：animateTo 260ms FastOutSlowIn 包住 panel = 4，卡片从下方 90vp 上浮 + 0.97 缩放 + 淡入；关闭 200ms 反向播放。

已知缺口

自绘浮层不接系统返回手势，现在按返回会直接收起播放页。下一步若有需要，在 Index 的 onBackPress 里判断 panel === 4 先关队列。
