为什么之前是两套

首页那套是更早版本为了解决「列表按钮点了没反应」临时拼的：bindSheet 和同节点的 bindContentCover 会互斥，所以改成普通节点叠层。它当时的重点是「能弹出来」，样式没跟播放页对齐。

为什么抽成组件

两处各写一份的话，下次调高度或圆角必然只改一处。抽成 QueueOverlay 后，尺寸/遮罩/动画只有一个来源，自检也守着「两个入口都必须用它」。

// 两个页面都这么调，样式只此一份 if (this.queueShow) { // 首页：this.panel === 4 → 播放页 QueueOverlay({ onClose: (): void => { this.queueShow = false; } }) }
