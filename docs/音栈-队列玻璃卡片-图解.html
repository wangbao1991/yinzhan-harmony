右图能看出四件事：四条边都露出封面（悬浮而不是贴边）；顶部有一条亮带；边缘有一圈细白线；底部有散开的投影。文字仍然是深灰，落在 72% 白上对比足够。

四层结构

LAYER 01
半透明底

rgba(255,255,255,.72)
浅色 72% 白、深色 66% 近黑。太透文字糊，太实就成板子。

LAYER 02
背景模糊

backdropBlur(18)
把底下的封面磨砂掉，才叫果冻，而不是「半透明纸」。

LAYER 03
顶部高光

linearGradient 180°
0~22% 白 .58 → 中段透明 → 底部 .14 回光。一层渐变做两头。

LAYER 04
亮边 + 柔影

1px 白 .9 + radius 30 / y 14
白线给边缘折射，投影偏冷才不显脏。

代码长什么样

// 外层：只负责描边和投影（这一层不裁剪，否则阴影会被切掉） Column() { Stack({ alignContent: Alignment.TopStart }) { // 高光层先画，压在内容下面，不参与点击 Column() .width('100%').height('100%') .linearGradient({ angle: 180, colors: this.glassGlint() }) .hitTestBehavior(HitTestMode.None) // 内容层：标题 + 列表 Column({ space: 6 }) { ... } .padding({ left: 18, right: 18, top: 18, bottom: 8 }) } .layoutWeight(1) .backgroundColor(this.glassFill()) // 半透明 .backdropBlur(18) // 磨砂 .borderRadius(30).clip(true) } .padding({ left: 12, right: 12, top: 10, bottom: 10 }) // 悬浮边距 .borderRadius(30) .border({ width: 1, color: this.glassRim() }) // 边缘折射 .shadow({ radius: 30, color: this.glassShadow(), offsetX: 0, offsetY: 14 })

为什么高光要放在内容下面

半透明白压在文字上会把标题洗淡。所以层序是：底色 → 高光 → 内容。高光只作用在空白处和列表的缝隙里，视觉上像「玻璃本身在发光」，而不是「蒙了一层雾」。

为什么 sheet 要设成全透明

卡片四周留了 12vp，这圈边距本来是要露出封面的。如果 sheet 容器自己有实色底，边距就成了一道色框，玻璃感立刻没了。所以播放页里这一处改成 '#00000000'，其它面板仍是实底。
