底栏：横滑切页 · 指示器跟手 · 滚动收成图标条

参考视频里那套「滑动 + 自动缩放 + 自动伸展」，拆开是三条独立机制：页面容器换成能跟手拖拽的 Swiper； 底栏加一个会横向移动的选中胶囊，位置取「当前页 + 拖动比例」；滚动进度直接驱动底栏的高度、宽度和文字透明度。 三条都挂在同一个连续量上，所以是变形，不是切换。

三个动作分别由什么驱动

关键在于三个量都是连续的，没有一个是「开关」

动作实现说明
滑动切页 Swiper + SwiperController 三个一级页从 Stack + visibility 搬进 Swiper，横滑由它接管；点底栏走 changeIndex()，和手势同一条过场
指示器跟手 onContentDidScroll → tabSwipe 回调给出「当前页 + 偏移比例」，写进 AppStorage；胶囊宽度固定 1/3，position.x 直接取这个百分比
滚动缩放 tabBarProgress → 尺寸 + 文字 原来只 opacity + translateY 淡出，栏体和文字一起消失；现在三者挂同一个 0~1 值上连续变形

改的时候踩到的两个坑

都不在「动画怎么写」，在「谁跟着谁动」

一、底栏变矮会把迷你播放条一起拽下去。 悬浮层是一个贴底的 Column：播放条在上、标签栏在下。标签栏高度从 62 掉到 46，整列就矮了 16， 底部对齐意味着顶部下移——播放条跟着上下晃。解法是给标签栏外面套一个固定 62 高的壳、底对齐， 收起时只有标签栏自己在壳里下沉，播放条完全不动。
二、Swiper 的 loop 必须关掉。 开着 loop 时，在设置页继续左滑会绕回首页，页面是滑过去的，但底栏指示器要从第 3 格瞬移回第 1 格， 用户会以为自己点错了。一级页是固定的三段，没有循环的必要。
