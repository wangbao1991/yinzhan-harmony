# 应用图标说明

## 资源布局

| 模式 | 资源路径 | 内容 |
| --- | --- | --- |
| 浅色 / 默认（**主图标**） | `AppScope/resources/base/media/app_icon.png`、`entry/src/main/resources/base/media/app_icon.png` | 图一：浅青渐变背景 + 三层青绿玻璃方块 + 音符 |
| 深色模式 | `AppScope/resources/dark/media/app_icon.png`、`entry/src/main/resources/dark/media/app_icon.png` | 图二：深蓝背景 + 发光玻璃方块 + 音符 |

为什么要放四处：

- `AppScope/app.json5` 的 `icon` 是**应用级图标**（桌面、应用信息、设置里看到的那张）。
- `entry/src/main/module.json5` 的 `icon` / `startWindowIcon` 是**入口 ability 图标与启动窗口图标**。
- `entry/src/main/ets/service/MediaSessionService.ets` 里的 `getMediaByNameSync('app_icon')` 会把同一张图用作**媒体通知 / 播控中心封面**，深色模式下同样会自动取 dark 版本。

`base` 与 `dark` 是 HarmonyOS 的深浅色资源限定词目录。同名资源由系统按当前颜色模式自动切换，**json5 与业务代码一行都不用改**（保持 `$media:app_icon`）。构建产物里可以直接核对：

```
resources/base/media/app_icon.png     ← 浅色主图标
resources/dark/media/app_icon.png     ← 深色图标
resources.index                       ← 同时登记上面两条路径
```

## 规格

- 1024 × 1024 PNG，RGBA、**alpha 全不透明**（无透明边、无自行裁的圆角；圆角蒙版由系统生成）
- 源文件为 1600 × 1600 JPEG，用 LANCZOS 缩放到 1024
- 深浅两张构图、主体完全一致，只有背景明度与发光强度不同

## 水印怎么去掉的

两张源图右下角都有「豆包 AI 生成」水印，位置约在原图 `x=1315..1565, y=1510..1568`。
那一块恰好是**纯平滑渐变背景、没有任何图案**，所以做了整块背景重建而不是粗暴裁剪：

1. 用「原图 − 大核高斯模糊」的局部高频差检出文字（含描边与抗锯齿像素），适度膨胀得到待填充区；
2. 用待填充区**之外**的真实背景像素拟合二维二次曲面 `c = f(u,v)`；
3. 用该曲面预测并替换文字区域颜色，矩形外与文字外的像素一律原样保留。

这样做没有笔画残影、没有 inpaint 的振铃噪点，也没有整块重建容易留下的边界色差。
可复用脚本：`scripts/icon/remove_watermark.py`（接受任意尺寸的同构图源图，坐标按比例换算）。

## 规范提醒

HarmonyOS 设计规范的**分层图标**（`layered_image.json` + 前景/背景各 1024×1024）能让桌面图标获得统一的圆角蒙版、最近任务圆形裁切与缩放动效，是上架应用市场时推荐的做法。

当前按需求使用**两张完整的立体玻璃图**，深色适配走 `dark` 限定词目录。若后续要改成分层图标，需要把玻璃方块从渐变背景里分离成独立前景层，并分别提供深浅两套；注意不要把原图直接裁圆角、也不要手动加内边距（系统蒙版会再叠一层 padding，图标会缩得很小）。

## 启动窗口（首帧前的系统启动页）

**启动窗口不能直接用桌面图标。** 桌面图标是带方形渐变背景的完整图，系统给它套圆角蒙版后看起来正常；但启动窗口没有蒙版，会把整张图当成方形贴图贴在浅灰白底上，形成「突兀的青色方块 + 四周大片留白」。因此单独做了一套启动资源：

| 模式 | 启动图 `startWindowIcon` | 底色 `startWindowBackground` |
| --- | --- | --- |
| 浅色 | `entry/src/main/resources/base/media/start_window_icon.png` | `#FFDCEDEB`（浅青白，与图标背景融合） |
| 深色 | `entry/src/main/resources/dark/media/start_window_icon.png` | `#FF0A1E2A`（深蓝，衬托发光） |

- `module.json5` 的 `startWindowIcon` 指向 `$media:start_window_icon`，**不再是** `$media:app_icon`；桌面图标本身不变。
- `start_window_background` 在 `base/element/color.json` 与 **`dark/element/color.json`** 各定义一份。原工程缺少 `dark/element`，深色模式下启动页其实仍是白底，一并补齐。
- 启动图的做法：把去水印后的完整图标缩到 640²，按半径做**径向 alpha 淡出**（`r<0.55` 完全不透明，`0.55~0.98` 用余弦平滑渐隐到全透明），再让窗口底色取图标背景色。方形边界随之完全消失，玻璃主体像浮在纯色底上，发光也保留。
- **没有采用「抠出透明主体」**：浅色图主体高光与背景色太接近，GrabCut 会在堆叠方块底部留下没抠净的青色块、边缘生硬且发光丢失；深色图同样有底部残留。径向淡出对两张图都稳定、无硬边界。
- 可复现脚本：`scripts/icon/make_start_window.py`（从 `app_icon.png` 生成两张 `start_window_icon.png`）。
