发现页 · 布局分层错了

标题层实际有四行高，内容却按一行让位

你圈到的现象是：「排行榜 / 推荐歌单」那排胶囊浮在榜单卡片上，平台那一排也被卡片穿过去， 往上滑再回弹时卡片直接钻进了平台行里。原因不在间距调得小，而在分层错了—— 大标题、分段、平台筛选原本全塞在同一个悬浮层里（实际约 116vp 高）， 可是下面的内容只按「一个大标题」（74vp）留了白，剩下的四十多 vp 就是重叠区。

不是「再往下挪一点」的问题，是留白和实际高度不是同一份账

顺带修的两处

同一个根因带出来的次生问题

  • 加载 / 空态贴顶：筛选带占了顶部一块，原来的「正在加载」「这里还没有内容」会挤在筛选带下面贴着， 现在包一层 layoutWeight(1) + justifyContent(Center)，在剩余区域里居中。
  • 遮罩压暗筛选带：标题层的渐变原来往下铺到 34vp，收窄到 16 之后只盖标题， 下面那排平台胶囊不再蒙一层灰。
  • 筛选带常驻而不是跟着滚：切平台、切分类不用先滑回顶部； 同时它和列表是两个独立的布局格，物理上不可能再互相穿过去。

自检加了 3 条，改回去会直接 FAIL

  • 标题层里不许出现 this.segment( 或 Chip({：筛选一旦塞回悬浮层，重叠就回来了。
  • 内容顶部留白必须 ≥ 80：低于这个数，标题层（大标题 + 副标题）会盖住第一行。
  • 标题层遮罩的 bottom 必须 ≤ 20：铺得太深会把下方筛选带压暗。
