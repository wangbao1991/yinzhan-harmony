每一段在做什么

进度区间元素动作
0.00 → 0.32选中指示器最先退。它是整条栏里最「重」的色块，早走一步，后面收窄时不会留一块颜色卡在半路。
0.02 → 0.34标签文字文字比图标先走。三格收窄时字会先挤在一起，先退掉就没有挤压感。
0.00 → 0.82整条宽度100% → 64%，只收右边。左边界钉死，图标自然聚拢，圆按钮才会从原来的位置长出来。
0.30 → 0.68图标文字走完才开始。此时栏已经收窄，看到的是「三个图标往左靠、逐个隐去」。
0.52 → 0.96白色底板最后溶解。它是「栏体」本身，留着它，视觉上是栏体化开，而不是整块被切掉。
0.34 → 0.80圆按钮0.72 → 1 放大浮现。有 scale 才有「弹出来」的重量感，纯淡入像颜色变深。
0.46 → 0.96播放胶囊从左边缘展开（scaleX 0.94→1，左锚点），同时上浮 4vp。接住圆按钮的节奏。
0.06 → 0.54外壳播放条比胶囊早一步退干净，中间是低透明度交叉，不会出现「两条播放条同时清晰」。
为什么这样比交叉淡化丝滑：交叉淡化是两条相反的曲线同时走， 中间必然有一段两者都半透明——看起来像两套 UI 叠着、糊成一片。 分段之后，同一时刻只有一个元素在明显变化，其余是静的， 眼睛读到的是连续的「动作」，而不是一次性的「切换」。
